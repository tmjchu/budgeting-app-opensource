## Changes and redistribution

Recolored to #263344; resized to 24px; adjusted outline weight and rounded joins; simplified SVG metadata/styles. Some viewBoxes padded to prevent clipping. Original shape geometry retained.

The runtime assets, generated icon review, and production app all use these adapted versions. The [Icon credits page](../../../public/icon-credits.html) carries titles, author/uploader credits, source links, license links, and change notices, and is copied into the production build. Retain it and the bundled MIT license files when distributing the app. The two MIT-licensed SVGs also retain the complete upstream notices in their source comments. The repository's Apache-2.0 license does not replace third-party asset terms.

- Microsoft / Fluent UI: full MIT notice in [MIT-Microsoft.txt](../../../public/licenses/MIT-Microsoft.txt), from the [upstream license](https://raw.githubusercontent.com/microsoft/fluentui-system-icons/main/LICENSE).
- Ant Design: full MIT notice in [MIT-Ant-Design.txt](../../../public/licenses/MIT-Ant-Design.txt), from the [upstream license](https://raw.githubusercontent.com/ant-design/ant-design-icons/master/LICENSE).
- CC Attribution: retain named-author credit, the source and license links, and the modification notice. SVG Repo does not specify the CC BY version for these three assets; no version is invented here. Confirm the version with the author or distributor before treating the license audit as complete.
- CC0 / Public Domain: credited voluntarily according to the distributor's listing. An uploader is not represented here as the original creator.

## Remaining provenance limitation

`credit-card-payment.svg` was drawn in this task using a user-provided screenshot as a visual reference. The screenshot's original creator and license are unknown. This is not one of the nine downloaded SVGs, and its source rights have not been verified. Obtain the original source/license or replace it with an independently sourced design before declaring all category artwork cleared.

The other 21 icons were authored as SVG paths in this task, without imported SVG files. No third-party attribution is asserted for them.

For future uploads, record the exact source, author, license (including version if stated), source hash, and modifications before use. Update `sources.json`, individual asset comments, this table, the public credits page, and the icon review attribution together.
